# NS16 网口对接

操作电脑经网线接入板子 `eth0`。板侧地址已保存，接入时保持不变。在操作电脑上按下列顺序配置并登录。

## 1. 接线

网线一端接入板子 `eth0`（RJ45），另一端接入操作电脑的以太网口。经 USB 以太网适配器接入时，使用插上后新出现的那块网卡。只改这一块网卡。

## 2. 配置操作电脑

在该网卡的 IPv4 设置中选择手动，按下表填写后保存。路由器留空。操作电脑原有的上网接口与默认路由保持不变。

| 项目 | 取值 |
| --- | --- |
| IP 地址 | `192.168.1.20` |
| 子网掩码 | `255.255.255.0` |
| 路由器 | 留空 |

同一网段内，除 `192.168.1.1`、`.10`、`.11`、`.103`、`.105`、`.106`、`.110`、`.111` 以外的其他地址也可以。不要使用 `192.168.88.0/24`。不要启用互联网共享。

macOS 路径：系统设置 → 网络 → 选中该网卡 → 详细信息 → TCP/IP → 配置 IPv4 选择“手动”。

保存后在操作电脑上执行：

```sh
ping -c 3 192.168.1.110
```

应收到应答。

## 3. SSH 登录

```sh
ssh nvidia@192.168.1.110
```

首次连接提示主机密钥时输入 `yes`。

| 项目 | 取值 |
| --- | --- |
| 用户名 | `nvidia` |
| 密码 | `nvidia` |
| `sudo` 密码 | `nvidia` |

登录后主机名为 `ubuntu`。

## 4. 板侧参数

| 项目 | 取值 |
| --- | --- |
| 接口 | `eth0` |
| 地址 | `192.168.1.110/24` |
| 网关 | `192.168.1.106` |
| DNS | `223.5.5.5` |

`eth0` 只有这一个地址。这根网线只用于登录。板子上网由记录主机 `192.168.1.106` 从外部网卡转发，配置见 [README_network_record.md](README_network_record.md)。
