# NS16 与机器狗

机器狗内部网段保持 `192.168.1.0/24`，地址不改。板子 `eth0` 使用 `192.168.1.110/24` 接入这张网，从而与狗内设备通信。从机器狗网络登录板子时，使用这一地址。

电脑用网线直连板子时，操作电脑设为 `192.168.88.1/24`，路由器留空，然后执行 `ssh nvidia@192.168.88.2`。账号与下文相同。

## 1. 地址

| 设备 | 地址 | 说明 |
| --- | --- | --- |
| 运动主机 | `192.168.1.103` | 机器狗原有地址 |
| 感知主机 | `192.168.1.105` | 机器狗原有地址 |
| 记录主机 | `192.168.1.106` | 用户 `ysc`，主机名 `ysc-perception` |
| 其他狗内设备 | `192.168.1.1`、`.10`、`.11` | 同网段，地址保持不变 |
| NS16 | `192.168.1.110/24` | 板子 `eth0`，这一地址不设网关 |

`192.168.1.103`、`.105`、`.106`、`.1`、`.10`、`.11` 留给机器狗。板子使用 `192.168.1.110`。

同一块 `eth0` 上还保留电脑直连用的地址。默认路由只走这一条。

| 项目 | 取值 |
| --- | --- |
| 接口 | `eth0` |
| 机器狗网段 | `192.168.1.110/24` |
| 电脑直连 | `192.168.88.2/24` |
| 网关 | `192.168.88.1` |
| DNS | `223.5.5.5` |

板子插在机器狗上时，`192.168.88.1` 不在这张网上，板子没有外网。`192.168.1.0/24` 内的通信不受影响。

## 2. 接线

网线一端接入板子 `eth0`（RJ45），另一端接入机器狗的网口。机器狗侧不需要改配置。

## 3. SSH 登录

操作电脑先连接到机器狗的 Wi-Fi，或从机器狗上的主机发起连接。然后执行：

```sh
ping -c 3 192.168.1.110
ssh nvidia@192.168.1.110
```

`ping` 应收到应答。首次连接提示主机密钥时输入 `yes`。

| 项目 | 取值 |
| --- | --- |
| 用户名 | `nvidia` |
| 密码 | `nvidia` |
| `sudo` 密码 | `nvidia` |

登录后主机名为 `ubuntu`。

若出现 `REMOTE HOST IDENTIFICATION HAS CHANGED`，在发起连接的那台机器上删除旧记录后重试：

```sh
ssh-keygen -R 192.168.1.110
ssh nvidia@192.168.1.110
```
